Future plan

Studio

A recording studio lane for installs, acoustic design, mix, master, and podcast work is on the board for later. It is not open for hire today.

We will only build this if Phyllux Tech turns into something that can honestly support a studio practice. Until then, treat this page as a direction, not a rate card.

If the studio opens later, the shape would likely include:

  • Turnkey studio design and install
  • Acoustic measurement and treatment plans
  • Remote and in person mix and master
  • Podcast production
  • Ongoing support for installed systems

Curious for the long game? Use contact with subject Studio interest. That is interest only, not a booking.
